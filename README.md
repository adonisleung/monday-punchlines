A make.fun Monday Morning Punchlines entry. The program writes one original joke about Monday mornings to `/output/entry.txt`.

The joke:

> I tried to call in sick on Monday. Monday picked up.

Run it with:

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` goes (default `/output`).
